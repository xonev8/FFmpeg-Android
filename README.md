# FFmpeg with HE AAC for Android ARMv8 & ARMv7
~Should I Stay or Should I Go

It's a personal project, don't expect a dev master blaster.

Static binaries of FFmpeg 8.1 and FFprobe 8.1 using a modern NDK, with full support for:
- **libfdk-aac** (`aac_he_v2` / `aac_he` / `aac_lc`)
- **libx264** (with NEON enabled for `arm64-v8a`)
- **libvpx** (VP8 and VP9)
- **libopus** and **libmp3lame**
